# 英语内容撰写规范（供内容作者与校验使用）

本文件是 `src/data/english/modules/*.ts` 的**统一撰写规范**。英语按**广州中考知识模块**
组织，不按教材单元（教材虽是沪教牛津版/上海版，但复习要按「考什么」组织）。

**关于「近三年广州中考真题」**：本应用**不复刻真题原文**（试卷文本受版权保护，

必须写明「原创仿真卷」，**不得声称是历年真题**。若需要真正的真题，请把官方卷面发给
维护者，按考点归类引用（只做考点索引，不抄全文）。

## 二、文件与导出形式

```ts
import type { EnglishKnowledge } from '../../../types';

export const topics: EnglishKnowledge[] = [ /* 条目 */ ];
```

模拟卷：`import type { EnglishPaper } from '../../../types'; export const papers: EnglishPaper[] = [];`

## 三、字段要求（`src/types.ts` 的 `EnglishKnowledge`）

公共字段（每条必填）：
- `id`：`eng-<模块代号>-<序号>`，如 `eng-vocab-affix-1`、`eng-grammar-tense-1`、`eng-reading-cloze-1`
- `grade`：`'all'`（英语知识按中考组织，不按册次；确需分级的用 `'7a'`…`'9b'`）
- `unit`：**知识分组**（模块页的筛选主标签），如「词根词缀」「同义辨析」「时态」「从句」「完形填空」「书面表达」
- `title`：中文标题（学生看得懂）；`enTitle`：英文知识点名或话题词
- `summary`：一句话说清「这一个知识点解决什么问题」
- `points`：**≥5 条**分层考点 `{ level, text, explain? }`，`level` 取 `'重点' | '次重点' | '了解'`，其中 `重点` ≥3 条
- `questions`：**≥5 道**题（`choice` 四选一 / `fill` 填空 / `short` 简答），每题含 `explanation` 与 `tags`

按模块补充的字段（**该模块至少要用到其中一类，且写足数量**）：
- 词汇：`affixes`（≥1 组，每组 ≥4 个例词）、`confusables`（≥3 组）、`collocations`（≥5 条）、`mistakes`（≥2 条）
  - `confusables` 每条**必须**给 `diff`（区别在哪）与 `exampleA`/`exampleB` 两个例句——只列同义词没有用
- 语法：`rules`（≥6 条，含 `form` 与 `example`、`cn`）、`mistakes`（≥3 条）
- 阅读：`passages`（≥2 篇，每篇英文正文 150—350 词 + `cn` 译文 + ≥4 道题）
- 听说：`scripts`（≥2 段，每段 80—200 词 + `cn` + `cues` 朗读提示 ≥3 条 + `tasks` ≥3 题）
- 写作：`writing`（`topic`、`requirements` ≥3 条、`samples` ≥2 篇分档范文（不同档次）、
  `usefulExpressions` ≥6 条）；范文要 80—120 词，`highlights` 每条 `sentence` 必须逐字出自范文
- 专题：`examTips`（≥5 条）+ 上述任一材料

## 四、内容质量硬要求

1. **英语必须地道**：语法、搭配、时态一致、标点（英文标点用于英文句内）都要正确；
   中文解释用中文标点。范文与语篇**全部原创**，不得抄教材课文、真题原文或版权材料。
2. **难度对齐中考**：词汇不超出初中 1600 词 + 中考常见拓展词；句子长度贴合初二下—初三水平。
3. **讲「区别」而不是「同义」**：近义词、易混语法、易错拼写都要写清「什么情况下用哪个」。
4. **面向应试**：`points[].explain` 要写「这一条在哪种题里考、怎么快速判断」。
5. **题目答案必须唯一且正确**，四个选项要有干扰性（典型错误：时态错、搭配错、词义误用）。
6. 中文引号用「」，英文引号用 `"`（仅用于英文句内引用）；不要用 Markdown 加粗。
7. 每条内容都是一次 `write` 写完的完整文件，不留 TODO、不留占位符。

## 六、分类词表（`wordList`）——初中词汇按类别整理

词汇是英语最大的一块，用户的要求是「**除了词根词缀，其他词汇也要按类别整理好，全部补上**」。
因此每条 `EnglishKnowledge` 可以挂一张分类词表：

```ts
wordList: [
  {
    group: '家庭成员',
    words: [
      { word: 'grandparent', phonetic: 'ˈɡrænpeərənt', pos: 'n.', cn: '祖父母', note: '复数 grandparents 常指祖父母两人' },
      { word: 'cousin', phonetic: 'ˈkʌzn', pos: 'n.', cn: '堂（表）兄弟姐妹', note: '不分男女、不分堂表，考试常考关系题' },
    ],
  },
]
```

字段要求：
- `word`：单词或短语（短语用 `phr.` 标注词性，如 `take part in`）
- `phonetic`：**只给容易读错的词**（可选）；不要给每个词都注音，那既费篇幅又没人看
- `pos`：词性缩写（`n.` `v.` `adj.` `adv.` `prep.` `pron.` `conj.` `num.` `phr.`）
- `cn`：中文释义，多义用「；」分隔
- `note`：**考点提示**——搭配、用法、易错点、作文可用的同义替换。空着等于没整理，
  但也不要每条都写「常用词」这种废话；不确定就留空

每个词表条目：**≥3 组、每组 ≥10 词**（词表条目总量要求见下），并且要配
`points`（≥5，其中「重点」≥3）、`questions`（≥5）。

### 词汇的三个维度（各写一套，允许同一个词在不同维度里出现）

1. **话题语义场**（主表，覆盖全部课标词汇）：人与自我 · 家庭与朋友 · 学校生活 ·
   饮食与健康 · 购物与消费 · 旅行与交通 · 天气与环境 · 科技与网络 · 文化与节日 ·
   体育运动 · 职业与工作 · 社会与规则……
2. **词性索引**（复习用）：名词（含可数性）· 动词（含及物性）· 形容词 · 副词 ·
   代词 · 数词 · 介词 · 连词
3. **中考考点**：不规则动词表 · 词形转换（名↔形↔副）· 高频短语动词 ·
   易错拼写与形近词

同一单词在不同维度重复是**有意的**（不同检索路径），不必去重；
`pnpm validate` 会统计总词量与去重后的词量，用来判断覆盖是否够。

## 五、校验（`pnpm validate` 会检查）

条目：`points` ≥5 且重点 ≥3、`questions` ≥5、`unit` 与 `summary` 非空、id 全局唯一；
各模块专属字段的数量下限见上；`confusables` 每条要有 `diff`；写作范文的 `highlights`
必须逐字出自范文；模拟卷按官方结构验卷（题量 61、笔试 110 分、各节分值一致）。
