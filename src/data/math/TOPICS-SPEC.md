# 数学「中考题型专题」内容规范（2027 版）

本文件是 `src/data/math/topics/*.ts` 的撰写规范。数学这一块与语文中考专题**共用同一套形态**：
一个**专题**（卷面板块）之下拆出若干**章节**（考点／题型），每节都要「讲透」：
讲解 + 要点 + 例题（分步解答）+ 同名专项训练。类型见 `src/types.ts` 的 `ExamTopic` / `ExamSection`。

## 一、卷面依据（2027—2029 广州中考数学）

依据广州市教育局《2027—2029 年广州市初中学业水平考试录取计分科目考试实施方案》及官方解读：

| 题型 | 题量 | 单题分值 | 小计 |
| --- | ---: | ---: | ---: |
| 单项选择题 | 10 小题 | 4 分 | 40 |
| 填空题 | 6 小题 | 4 分 | 24 |
| 解答题 | 9 小题 | — | 86 |
| **全卷** | **25 小题** | | **150** |

- 满分由现行 120 分调整为 **150 分**，考试时长**仍为 120 分钟**。
- 官方口径：**「题型题量不变、考试时长不变、优化分值结构」**，客观题（选择+填空）共 **64 分**、
  占 42.7%，与现行方案客观题占比（40%）大致相当；**选择填空每题由 3 分提升为 4 分**（共 16 道）。
- 现行（120 分）结构为 选择 10×3=30 · 填空 6×3=18 · 解答 9 题 72 分，可作题位与难度梯度的参照。
- **官方未逐题公布的分值一律标注为「推算」**，不虚构分值。

## 三、字段下限（`scripts/validate-exam-topics.ts` 会逐项检查）

| 字段 | 下限 | 说明 |
| --- | --- | --- |
| `paper` | — | 2027 口径的卷面定位（含分值区间） |
| `summary` / `trendSummary` | — | 一句话：这一块怎么考、拿分靠什么 |
| `trends` | **恰好 5 条** | 2021—2025 一年一条，写「考查形态／分值区间／选材倾向」 |
| `angles` | ≥6 | 命题角度：`angle` + `years` + `detail`（怎么写才对） |
| `steps` | ≥6 步 | 解这一类题的整体流程；**≥3 步带 `demo`**（完整走一遍） |
| `templates` | ≥3 组 | 解题模板（每组 items ≥3 条） |
| `scoring` | ≥4 条 | **步骤分**：写到哪一步给几分（数学最看这个） |
| `pitfalls` | ≥4 条 | 易错与失分 `{ wrong, right, why }` |
| `sections` | 与第二节清单一致 | 每节：`intro` ≥60 字 + `rules` ≥3 条 + **`examples` ≥3 条** + `pitfalls` ≥2 条 |
| 每节题目 | **≥4 题**（重点节 ≥6） | `tags[0]` = 该节 `name`；`drills` 里有同名分组 |
| `questions` | **≥45 题/专题** | 训练总量硬指标 |

## 四、数学的「例子」怎么写（与语文同一字段、不同用法）

`ExamExample` 对数学是这样用的：

```ts
{
  text: '已知抛物线 $y=x^2-2x-3$，求它与 $x$ 轴交点的坐标。',   // 题目（行内公式用 $…$）
  steps: [                                                    // 分步解答（每步一行）
    '令 $y=0$，得 $x^2-2x-3=0$。',
    '因式分解：$(x-3)(x+1)=0$，所以 $x=3$ 或 $x=-1$。',
    '交点坐标为 $(3,0)$、$(-1,0)$。',
  ],
  answer: '$(3,0)$、$(-1,0)$',
  analysis: '怎么想到的：抛物线与 $x$ 轴交点就是 $y=0$ 的解，先想能不能因式分解……',
}
```

- 每节的 3 条以上例子要**覆盖这一节的不同小类**（不要三道同型题）。
- `analysis` 一律写「**怎么想到的**」：这道题看到什么条件该想到什么模型／辅助线／公式。
- 公式写法：**正文行内公式用 `$…$` 包裹**；`formulas` 之类字段用不带定界符的 KaTeX 源码。
  渲染层是 KaTeX，失败会降级为纯文本，不会白屏。

## 五、硬规矩

1. **不照抄真题**：题目、材料、数据全部自拟或改编（可对标近年广州卷的题型与难度），
   **不得声称是某年真题**；`trends` 只写形态与分值，不写某年某题原文。
2. **答案必须可验证**：填空题答案写成最简形式；有等价写法时用 `|` 分隔
   （如 `x=3|x=3,y=0`），判分器支持 `|` 备选；选择题 4 选项、答案只能是 A/B/C/D，
   且四个选项字母分布要分散。
3. **不编造**：数据、统计结论、定理名称与适用条件都要准确；拿不准的数字不写。
4. 中文引号用「」，正文不用 Markdown 加粗；`id` 规则：题 `mth-<专题短名>-qNN`（两位序号），
   章节名与题目标签、`drills[].name` 三者**同一字符串**。
5. 一次 `write` 写完整文件，不留 TODO、不留占位符。

## 六、攻破标准

与语文中考专题一致：**全题过关**（该专题每一道题都答对过才算攻破），
所以题量上去了质量必须跟上——一道讲不清的题会永久卡住学生的进度。
