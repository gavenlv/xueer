# 物理内容撰写规范（`src/data/physics/modules/*.ts`）

本文件是物理内容的**唯一契约**：数据形状、图解 DSL、质量红线、校验口径都在这里。
写内容前先读完；写完必须跑 `npx tsc --noEmit`（图解 DSL 是强类型的，写错会立刻报错）。

---

## 一、卷面依据（2027—2029 广州中考，官方口径）

| 项目 | 数值 |
| --- | --- |
| 科目总分 | **100 分** = 笔试 **90 分** + **实验操作考试 10 分**（另场） |
| 笔试时长 | **60 分钟**，闭卷 |
| 选择题 | **10 小题 × 3 分 = 30 分** |
| 非选择题 | **6 小题 = 60 分** |
| 非选择题型 | **解答与计算 · 探究与实验 · 阅读与理解**（强调综合性、探究性、开放性） |

依据：广州市教育局《2027—2029 年广州市初中学业水平考试录取计分科目考试实施方案》
（穗教规字〔2025〕1 号）及官方解读。官方若调整，改 `POLITICS_STRUCTURE` 式的常量即可，
代码不用动（物理为 `PHYSICS_STRUCTURE`）。

**题型导向直接决定内容取向**：非选择题不是「填空 + 计算」两大块，而是
**阅读与理解**（给一段情境化材料，让学生自己提取物理量）、**探究与实验**、
**解答与计算**。所以物理内容不能只写「公式 + 套数」，必须写清
「这个情境里哪些量是已知的、为什么用这条规律、单位怎么统一」。

## 二、理科取向：讲解必须回答「怎么理解、怎么应用」

每条内容（一个**知识点**）按固定顺序组织，**不允许**写成「定义 + 公式 + 例题」的堆砌：

1. `question` —— 这个知识点要回答的**问题**（从问题切入，不从定义切入）。
   例：「为什么汽车刹车后还要滑行一段距离？」而不是「什么是惯性」。
2. `keyIdea` —— 理解的关键一句话（学生记住这一句就能自己推）。
3. `steps[]` —— **理解过程**，3—6 步，每步一个 `heading` + `body`，
   **每步尽量配 `figure`**（图文并茂：理科的图不是装饰，是把文字讲不清的关系画出来）。
   推荐的步骤顺序：
   - 「先看现象」——生活/实验里能看到什么；
   - 「抓住哪个量」——从现象里抽象出物理量，说清它的含义与单位；
   - 「建立关系」——为什么会有这个关系（比例、控制变量、守恒、等效……）；
   - 「换个情境再想一遍」——改变一个条件，结论怎么变（这是中考最爱考的追问）。
4. `apps[]` —— **应用/例题**：`scene`（情境）→ `model`（抓出哪些量、用哪条规律）
   → `steps[]`（规范解答步骤）→ `result`（结论）。至少 2 个，覆盖「生活应用」与「计算」。
5. `formulas[]` —— 公式必须写 `usage`（适用条件与变形用法）。
   **只写公式不写适用条件是物理内容最常见的失分源**（如 $p=\rho gh$ 只适用于液体与柱体）。
6. `confusions[]` —— 易错辨析（`wrong` / `right` / `why`），≥2 条。
7. `compares[]` —— 对比表（概念对照、条件对照），≥1 张，`left`/`right` 是**表头名**。
8. `examAngles[]` —— 命题角度与考法，≥2 条；**不写具体年份**（不编造真题年份）。
9. `materials[]` —— 中考非选择题形态的综合题，≥1 组，每组 2—3 问，每问带
   `answer`、`rubric`（踩分点）与分值；题目类型按上面三类非选择题型写。
10. `questions[]` —— **练习，每个知识点不少于 8 道**（见第四节）。

## 三、图解 DSL（`PhysicsFigure`）

图**不用图片文件**：用数据描述图元，由 `src/components/PhysicsFigure.tsx` 画成内联 SVG。
好处是离线、可换主题、可朗读、可检索，发布包里不增加素材。

### 3.1 坐标与比例

- 所有坐标是 **0—100 的画布单位**，**左上角为原点、y 轴向下**。
- `view`：`wide`（默认，100×62.5，适合电路与受力图）、`square`（100×100，适合图像）、
  `tall`（100×140，适合温度计、斜面）。
- 角度单位是**度**，`0` = 正右，**逆时针为正**（渲染器内部取负，作者按数学直觉写即可）。

### 3.2 每张图必填

```ts
{
  id: 'fig-mech-inertia-1',
  title: '急刹车时乘客身体前倾',        // 图题（画在图下方）
  caption: '车停了，人还要保持原来的运动状态', // 一句话点出这张图要看什么
  alt: '一辆向右行驶的汽车突然刹车，车内乘客上半身向右倾斜', // 必填：朗读与无障碍
  prims: [ ... ],
}
```

`alt` 是**必填**：整页朗读靠它把图读出来，检索也靠它把问题搜到图上。校验器会检查。

### 3.3 图元清单

**通用图元**

| 图元 | 参数 | 用途 |
| --- | --- | --- |
| `line` | `x1 y1 x2 y2 dashed? tone? width?` | 辅助线、法线、光线、导线 |
| `arrow` | `x1 y1 x2 y2 both? dashed? tone? width? label? labelDx? labelDy?` | **力的箭头**、速度、电流方向、拉伸示意 |
| `rect` | `x y w h tone? fill? dashed? rx? label?` | 物体、区域、容器 |
| `circle` | `cx cy r tone? fill? dashed? label? labelDx? labelDy?` | 球、质点、轮子 |
| `poly` | `points closed? tone? fill? dashed?` | 多边形、折线轮廓 |
| `arc` | `cx cy r from to tone? dashed? arrow?` | 圆弧、轨道、角度弧 |
| `text` | `x y text anchor? size? tone?` | 文字标注（`size` 默认 4.2 画布单位） |
| `angle` | `x y from to r? label? tone? right?` | 角标记；`right: true` 画直角方框 |
| `axis` | `x y w h xLabel yLabel xTicks? yTicks? grid? origin?` | **坐标图像**（刻度 `at` 为 0—1 的相对位置，`label` 是刻度文字） |
| `curve` | `points tone? dashed? width? arrow?` | 图像曲线、光路、轨迹 |
| `hatch` | `x y w h tone? gap?` | 地面/墙面/不透光区（斜线阴影） |

**电学符号**（按教材标准画法，自带引线，可直接串在导线上）

| 图元 | 参数 | 说明 |
| --- | --- | --- |
| `battery` | `x y vertical? label? cells?` | 电源：长线正极、短线负极 |
| `switch` | `x y closed? vertical? label?` | 开关：`closed: true` 闭合 |
| `bulb` | `x y label?` | 灯泡（圆圈+叉） |
| `resistor` | `x y vertical? label? w? h?` | 定值电阻 |
| `rheostat` | `x y vertical? label?` | 滑动变阻器（带滑片） |
| `meter` | `x y kind: 'A'\|'V' label?` | 电流表 / 电压表 |
| `junction` | `x y` | 导线结点（实心点） |

**光学元件**：`lens`（`kind: 'convex'|'concave'`，`y` 为光心）、
`mirror`（`len`、`angle`）、`surface`（`kind: 'water'|'glass'`，两点定界面）。

**力学元件**：`pulley`（`kind: 'fixed'|'moving'`）、`lever`（两端点 + `pivot` 0—1 支点）、
`incline`（`x y w deg`，自动画直角三角形）、`spring`（两点 + `coils`）、
`beaker`（`fill` 水位 0—1）。

**热学与磁**：`thermometer`（`value` 液柱 0—1）、`magnet`（左 N 右 S）、
`coil`（通电螺线管，`turns`；`frontCurrent` 定 N/S 极性，`showCurrent` 才代画电流箭头）、
`compass`（`deg` 北极指向）。

**计时与标记**：`stopwatch`（机械停表双盘：`minute` 小盘 0—15 min、`second` 大盘 0—60 s
且**一圈只有 30 s**，分度值 0.1 s；读数题靠小盘判断大盘是哪一圈）、
`dot`（标点：力臂的垂足、光学光心与焦点、支点、交点；`hollow` 画空心圈）。

## 四、练习：每个知识点不少于 8 道，且**全部过关才算掌握**

用户明确要求：**所有的习题都过关了才算是掌握**。因此练习题不是「凑够数量」，
而是这个知识点的**验收清单**——每一道都要问一个不同的角度，学生全过了才算真的会。

硬性要求：

- 每个 `points` 覆盖到的知识点，`questions` **≥ 8 道**（校验器检查）；
- 题型要**混搭**，不允许 8 道全是选择题：
  - `choice` ≥ 4 道（概念判断、图像判断、单位与估测、情境选择）；
  - `fill` ≥ 1 道（数值 + 单位，答案写法用 `|` 列出可接受形式，如 `'2.5|2.50'`）；
  - `short` ≥ 2 道，且必须**一题计算、一题实验或说理**：
    - 计算题：给 `answerSteps`（规范解题步骤，分步给分）+ `rubric`；
    - 实验探究题：给 `rubric` 踩分点（器材、操作、数据、结论各一条）；
    - **作图题**：`short` + `answerFigure`（标准作图），学生画完展开对照自评。
- 选择题必须有配图的至少 1 道（`figure`），且有 1 道带 `answerFigure` 的作图题——
  物理中考离不开图，练的时候就得看图。
- 选择题答案字母**分布均匀**（校验器会告警单字母占比 >45% 或某字母缺失）。
- 每题都要有 `explanation`：**讲清为什么**，不要只说「故选 B」；
  干扰项要逐一点出错在哪（这是理科讲解的价值所在）。
- 数值题的数据要**符合真实量级且自洽**：不要出现「人步行速度 30 m/s」。
  自编数据可以，但要能算得通、单位统一。

`short` 题的自评依赖 `rubric`；`answerSteps` 与 `explanation` 的分工是：
`explanation` 讲「为什么这么做」，`answerSteps` 给「卷面上该怎么写」。

## 五、命名与结构约定

- 知识点 id：`phy-<模块短名>-<序号>`，如 `phy-mech-1`；
- 题目 id：`phy-mech-1-q1` … `phy-mech-1-q8`；材料题：`phy-mech-1-m1`，设问 `phy-mech-1-m1-q1`；
- 图 id：`fig-<模块>-<主题>-<序号>`；
- `unit` 写教材归属：人教版八上/八下/九年级全一册 + 章节，如
  `'人教版八下 · 第 7 章 力'`（同一章的多条内容共用同一个 `unit`，它同时是模块页的筛选标签）；
- `grade`：八年级上册 `'8a'`、八下 `'8b'`、九年级 `'9a'`/`'9b'`，跨年级综合写 `'all'`；
- 中文引号统一用「」，**正文不使用 Markdown 加粗**（题目与答案里不出现标记符号）；
- 公式写进 `tex`（KaTeX），形如 `'W = Fs'`、`'p = \\frac{F}{S}'`；
  正文里也可以用 `$...$` 行内公式（渲染器已支持）。

## 六、质量红线

1. **物理量、单位、公式适用条件不能错**：这是物理内容的生命线。
   写「$p=\\rho gh$ 适用于任何情况」这样的句子等于教错。
2. **不编造实验数据与结论**：自编情境要符合真实物理量级；
   引用公开事实（如「复兴号最高运营时速 350 km/h」）要确有其事。
3. **不做偏题怪题**，不超纲（广州中考不考初中课标之外的内容）。
4. **图示必须能自洽**：箭头方向、光路可逆、电路短路的判断要画对；
   电路图里电流表**串联**、电压表**并联**，画错就是教错。
5. **不写具体年份的真题**：`examAngles` 不填 `years`，材料题标「原创仿真」。
