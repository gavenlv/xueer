# 道德与法治内容撰写规范

本文件是 `src/data/politics/modules/*.ts` 的统一撰写规范。**按历史科目的要求做**：
对齐 2027—2029 广州中考、从初三总复习与备考角度组织、每条内容给全「备考八块」。

## 一、卷面依据：2027—2029 年广州中考道德与法治（官方结构）

依据广州市教育局《2027—2029 年广州市初中学业水平考试录取计分科目考试实施方案》
（穗教规字〔2025〕1 号）附件 2：

| 题型 | 题量 | 分值 |
| --- | ---: | ---: |
| 单项选择题 | 17 小题 | 34 |
| 非选择题（阅读材料，回答问题） | 3 小题 | 36 |
| **全卷** | **20 小题** | **70** |

考试方式：**闭卷笔试**，60 分钟，与历史同场分卷（15:00—16:00 道法，16:15—17:15 历史）。
全科总分 70 分（原 90 分，属「适当减分」科目）。

**关于「历年真题」**：本应用**不复刻真题原文**（试卷文本受版权保护）。模拟卷按上表结构与
近年时政热点、设问方式编写，`basis` 必须写明「原创仿真卷，非历年真题」。

## 三、每条内容的「备考八块」（缺一块 `pnpm validate` 会报错）

1. `mainline`：一句话主线——这个单元在讲什么、为什么在中考里重要
2. `points`：**核心观点与考点分层**，≥5 条、其中 `重点` ≥3；`level` 取
   `'重点' | '次重点' | '了解'`；`text` 必须写成**可以直接抄进答题卡的规范表述**
   （如「我国是人民民主专政的社会主义国家，国家一切权力属于人民」），
   `explain` 写「这一条在什么题里考、怎么用」
3. `keySentences`：**必背金句与答题术语** ≥3 条——道法材料题给分靠规范表述，
   学生写「大家要爱护环境」不得分，写「坚持人与自然和谐共生，践行绿色发展理念」才得分
4. `confusions`：**易错辨析** ≥2 条（`{ wrong, right, why }`），写真实易错，
   例如「权力」与「权利」、「法制」与「法治」、「道德义务」与「法定义务」、
   「人民代表大会」与「人民代表大会制度」
5. `compares`：**关联与对比表** ≥1 张（`{ title, aspect, left, right, rows }`）——
   跨单元/跨册对照或概念对照（权利 vs 义务、道德 vs 法律、中国 vs 世界…）
6. `examAngles`：**命题角度与考法** ≥2 条（`{ angle, years?, detail }`）——
   `years` 只在确属常识表述时才写，**不得编造某年某题的原文**
7. `materials`：**材料大题** ≥1 组（`{ id, material, questions }`）：
   `material` 用 `【材料一】…\n【材料二】…` 写 2—3 则材料（可引用**公开的**政策文件表述、
   权威媒体报道、法律条文；也可自撰贴近现实的情境）；每组 **≥2 个设问**，
   `stem` 写明分值（如「（1）……（4 分）」）；每题给完整参考答案与 3—5 条 `rubric` 踩分点
8. `questions`：≥5 道选择题（`choice`，4 选项 + `explanation` + `tags`）

时政专题条目（`pol-current`）另需 `hotspots` ≥1 个：
`{ event, background, angles: [{ angle, point, answer }] }`——写清事件、背景，
以及**可以从哪几个教材考点切入答题**（每个角度给出规范答案）。
`background` 只写可核查的公开信息，**不得编造事件细节与数据**。

## 四、内容质量硬要求

1. **表述必须与教材、权威口径一致**：涉及宪法、法律、国家制度、党的路线方针的表述，
   一个字都不能错（这是道法最容易出错也最要命的地方）。
2. **不编造数据与事件**：引用数据只能来自公开统计公报或官方报道；拿不准就不写数字。
3. **面向应试**：每一条都要能回答「考场上我怎么写才得分」。
4. 中文引号用「」，不要 Markdown 加粗。
5. 一次 `write` 写完整文件，不留 TODO、不留占位符。

## 五、校验（`pnpm validate` 会检查）

条目：`unit` 与 `mainline` 非空、`points` ≥5 且重点 ≥3、`keySentences` ≥3、
`confusions` ≥2、`compares` ≥1、`examAngles` ≥2、`materials` ≥1（每组 ≥2 问、
每问有参考答案与踩分点）、`questions` ≥5、id 全局唯一；
时政条目另查 `hotspots` ≥1 且每个角度有 `point` 与 `answer`；
模拟卷按官方结构验卷（17 选择 34 分 + 3 材料 36 分 = 20 小题 70 分、60 分钟、闭卷）。
