# 语文「中考专题」内容规范（2027 版）

本文件是 `src/data/chinese/zh-topics/*.ts` 的统一撰写规范，也是**七个专题的唯一口径**。
每个专题 = 一个 `ChineseExamTopic`：**近五年考情 + 专门讲解 + 专项训练**三件套。

核心目标（用户原话）：**「每个专题都有详细的讲解、大量的训练，攻破每个专题，就能把中考对应板块的分数拿下。」**
因此写内容时始终问自己两句：**这一块怎么一步步拿分？学生练够了吗？**

---

## 一、卷面依据：2027—2029 年广州中考语文（官方口径）

依据广州市教育局《2027—2029 年广州市初中学业水平考试录取计分科目考试实施方案》
（穗教发〔2025〕32 号）及官方解读：

- 满分 **140 分**（现行 120 分），考试时长 **120 分钟**（保持不变）。
- 另设 **附加题 8 分（名著阅读）**，**附加题得分计入总分，但全卷得分不得超过 140 分**。
- 「试卷结构保持稳定，主要考查**积累与运用、阅读与鉴赏、表达与交流**，**分值占比与现行方案基本持平**」。

现行（120 分）卷面结构（官方附件实测，供定位用）：

| 板块 | 题量 | 分值 |
| --- | ---: | ---: |
| 积累与运用 | 约 6 小题 | 24 |
| 阅读与鉴赏 | 约 14 小题 | 46 |
| 写作与表达 | 1 小题 | 50 |
| 全卷 | 约 21 小题 | 120 |
| 附加题（名著阅读） | 1 小题 | 8 |

**按「占比基本持平」推算的 140 分卷**：积累与运用 ≈28 分 · 阅读与鉴赏 ≈54 分 · 写作与表达 ≈58 分。
这是**推算值，不是官方逐题分值**——写 `paper` 与讲解时一律用区间表述（如「约 24—28 分」），
不要写成确定数字，也不要编造逐题分值表。

## 三、版权红线（**最重要的一条**）

- **不复刻任何一年的真题原文、材料、题干、选项、答案**。真题受版权保护。
- `trends` 只写**考查形态 / 分值区间 / 选材倾向**；`angles.years` 只写年份区间。
- 训练题**全部原创**：材料自己写（可引用公开政策文件、权威媒体表述、教材原文、名著常识），
  情境自己设，绝不整段搬运真题材料。
- 古诗文默写题**必须用教材原文**（这是教材内容，允许且必要）；名著题以**情节与人物常识**为主，
  确需引用原著字句时只用一个短语，不复制整段。

## 四、每个专题必须写全的字段（数量为**下限**，校验器会逐项检查）

| 字段 | 下限 | 写法要求 |
| --- | --- | --- |
| `paper` | — | 2027 口径的卷面定位，含分值**区间** |
| `summary` | — | 一句话说清「考什么、拿分靠什么」 |
| `trends` | 恰好 5 条 | 2021—2025 一年一条，写「考查形态 / 分值区间 / 选材倾向」 |
| `trendSummary` | 1 条 | 一句话趋势结论：现在怎么考、往哪走 |
| `angles` | 6 条 | 命题角度（`angle` + `years` + `detail`），写「怎么设问、怎么答」 |
| `steps` | 6 步 | 分步讲解；**至少 3 步带 `demo`**（按这一步完整做一遍的示范） |
| `templates` | 3 组 | 答题模板，可直接背下来套用；每组 `items` ≥3 条 |
| `scoring` | 4 条 | 评分点：**写到什么才给分**（按分值点拆分） |
| `pitfalls` | 4 条 | 易错与失分 `{ wrong, right, why }` |
| `drills` | 5 组 | 训练分组；`name` **必须与该专题题目 tags 里的组名完全一致** |
| `questions` | **45 题** | 「大量训练」硬指标；每题 ≥2 个 tags，**第一个 tag 必须是某个 `drills[].name`** |

字段类型见 `src/types.ts` 的 `ChineseExamTopic`（不要改类型）。
题目类型可用：`choice`（4 选项）/ `fill`（填空）/ `short`（简答，需 `rubric` 踩分点）。
主观题（简答）**必须给 `rubric`**，这是「答到什么程度给几分」的依据。

## 五、七个专题的题型清单（逐项覆盖，这是「分门别类」的落点）

> **每个类目都要有一个同名的「章节」**（见第八节）：第五节是类目清单（写什么），
> 第八节给出**每一节的精确名称与子类拆分**（怎么讲透）。两者必须一一对应。

### ① 积累与运用（`zht-jilei`）≥45 题
字音（形声误读、形近误读、多音字、统读字）· 字形（同音替代、形近、偏旁） ·
词语与成语（望文生义、对象误用、褒贬颠倒、近义辨析）· 病句（成分残缺、搭配不当、
语序不当、结构混乱、不合逻辑）· 标点符号 · 句子衔接与排序 · 仿写与修辞 ·
图文转换（表格数据、漫画、徽标、流程图）· 口语交际与情境表达（拟写标语/开场白/结束语、
劝说、转述、补写对话、辩论）· 材料概括与信息提取 · 对联与传统文化常识 · 书法与书写规范。

### ② 古诗文默写（`zht-moxie`）≥45 题
直接默写（上下句）· 理解性默写（给提示语/情境）· 主题式与批注式默写（如「问答形式的诗句」）·
六句选四句与多句选答 · 易错字形（同音替代、形近字、通假字）· 篇目范围（课标必背 60 篇
＋教材「课外古诗词诵读」）· 名句归类（写景、言志、思乡、爱国、哲理、友情）。

### ③ 文言文阅读（`zht-wenyan`）≥45 题

内容理解与概括 · **课内外比较阅读**（异同、表格填空、共同主题）· 人物形象与写作手法 ·

### ④ 古诗词鉴赏（`zht-gushi`）≥45 题
意象与画面 · 炼字（动词/形容词/数量词/叠词）· 手法（比喻、拟人、用典、对比、动静、虚实、
借景抒情、直抒胸臆）· 情感主旨 · 语言风格 · 联句理解（如「表现时序更替、蕴含自然理趣的是哪一联」）·
**仿照批注写赏析** · 课内外比较阅读 · 名句理解性赏析。

### ⑤ 现代文阅读（`zht-xiandai`）≥50 题（题量最大）
**文学类文本**：内容理解（选择）· 事件/情节概括 · 语言赏析（含**叠词**、修辞、句式）·
人物形象 · 标题与结尾的作用 · 情感与启示（开放）· 写法探究（伏笔、照应、线索、详略）。
**实用类/非连续性文本**：信息辨析（选择）· 推断是否合理（选择）· 材料概括 ·
**图表数据读取** · 跨材料比较与整合 · 迁移运用（借鉴材料思路解决新问题）· 拟写标题/导语。

### ⑥ 名著阅读与整本书阅读（`zht-mingzhu`）≥45 题
情节梳理与排序 · 人物形象与性格 · **人物心理（表格填空）** · **内心独白补写**（关联前后情节）·

## 八、章节：每个类目与子类都要「讲透」（**本规范的核心要求**）

用户对第一版内容的评价是「**还是太过于粗糙**」，原话是：

> 如第一部分，包括考字音、字形、词语与成语、病句、标点、句子衔接与排序、仿写与修辞、
> 图文转换、口语交际与情境表达、材料概括、对联与文化常识、书法十二类，我的意思是，
> **每个类别都要讲透**，如病句，每个类型的病句，类型，并举例，**每一种类型都有独立的章节讲透**，
> 和足够的例子讲解，和练习，其他每个部分和类别，都是同理。

所以专题之下要有一层 **`sections`（章节）**：一个类目／子类 = 一节 = 一个「讲练单元」。
章节用 `ChineseExamSection`（见 `src/types.ts`）：

| 字段 | 下限 | 写法要求 |
| --- | --- | --- |
| `name` | — | 章节名，**必须与第八节给出的名称逐字一致**；同时是 `drills[].name` 与题目的首个 `tags[0]` |
| `intro` | ≥60 字 | 这一节讲什么、**怎么判断**（不要复述定义，要写「一眼看什么」） |
| `rules` | ≥3 条 | 判定要点／口诀：每条一句可操作的话（如「看到『能否』『是否』立刻找后面的两面词」） |
| `examples` | **≥3 条** | 例子讲解：**正误对照**，每条给 `text` + `analysis`（错在哪、属于哪一小类）；错例要给 `fix` 修改后的句子 |
| `pitfalls` | ≥2 条 | 本节易错。**两种写法都可以**：① 字符串，一句话写「错在哪 → 怎么办」（多数情况够用）；② 三行对象 `{ wrong, right, why }`（与专题级一致，坑比较绕时用）。同一个专题内尽量统一 |
| 该节题目 | **≥4 题**（重点类目 ≥6） | 每题 `tags[0]` = 该节 `name`，`drills` 里有同名分组 |

**讲练必须一一对应**：`sections[].name` ↔ `drills[].name` ↔ 题目 `tags[0]`，三者是同一个字符串。
学生看完一节，点「刷这一节」就进 `/practice/zh-topics/<专题 id>?tag=<章节名>`。

## 九、写作规范

1. 中文引号用「」，**正文不用 Markdown 加粗**。
2. 解析要写「**怎么想到的**」，不能只给答案：先说这一步在找什么，再说为什么选它。
3. **不编造**：数据、政策表述、名著情节、教材篇目都要真实可核查。
4. 每题 `tags` 至少 2 个，第一个必须是 `drills` 里的组名（分组刷题按它组卷）。
5. id 规则：题 `zht-<专题>-qNN`（两位序号，从 01 起连续，**已存在的编号不要改动**——学生的过关记录绑在题目 id 上）；**子 id 前缀必须与专题 id 一致**。
6. 一次 `write` 写完整文件，不留 TODO、不留占位符。

## 十、攻破标准

本模块启用**全题过关**策略（`lib/progress.ts` 的 `ALL_QUESTIONS_PREFIXES` 含 `zht-`）：
**该专题每一道题都曾答对**，专题才算攻破。所以题量上去了质量必须跟上——
一道自己都讲不清的题，会永久卡住学生的「攻破」进度。
