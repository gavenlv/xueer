# 化学内容撰写规范（`src/data/chemistry/modules/*.ts`）

本文件是化学内容的**唯一契约**：数据形状、图解 DSL、质量红线、校验口径。
写内容前读完；写完必须跑 `npx tsc --noEmit`（图解 DSL 与字段都是强类型的，写错会立刻报错）。

## 二、讲解必须走「三重表征」

化学的难点在于**同一个现象有三种表达**：看得见的（宏观）、看不见的粒子（微观）、
写出来的符号（化学式与方程式）。学生「会背不会用」几乎都是在三者之间断了链。
因此每个知识点的 `steps` 按三重表征组织，每步标出 `representation`：

1. **宏观**（`representation: '宏观'`）——现象、颜色、状态、条件；
2. **微观**（`'微观'`）——分子、原子、离子怎么变、什么没变（质量守恒的微观解释就在这里）；
3. **符号**（`'符号'`）——化学式、化学方程式、离子符号怎么写、怎么配平；
4. **应用**（`'应用'`）——生活与生产中的用途、检验与鉴别、计算。

每步尽量配图：宏观配装置图或现象图，微观配粒子模型（`atom` / `molecule`），
符号步可以配「粒子模型与方程式对照图」（这是把断链补上最有效的一张图）。

## 三、化学特有字段

`ChemTopic` 在理科共有字段之外，还有三组化学专有内容：

- `equations[]`（**化学方程式**）：`equation`（完整式子，如 `2H_2 + O_2 \xlongequal{点燃} 2H_2O`
  这种 LaTeX 不必写，直接写真式更好读）、`condition`（反应条件：点燃／加热／高温／催化剂／通电）、
  `phenomenon`（现象，学生要会描述）、`note`（配平要点与易错）。
  **方程式一律用可读的文本写**：`'2H2 + O2 =点燃= 2H2O'` 这类写法不好读，
  推荐 `'2H₂ + O₂ —点燃→ 2H₂O'`（用下标字符与箭头），全库风格要统一。
- `experiments[]`（**实验**）：`purpose` / `apparatus` / `figure`（装置图）/ `steps` /
  `phenomenon` / `conclusion` / `cautions`。**注意事项必写**（中考必考：先熄灯还是先撤导管、
  试管口略向下倾斜、不能用嘴吹灭酒精灯……）。
- `formulas[]`：计算关系与化学用语规则，**每条都要写 `usage`（适用范围）**：
  如相对分子质量、元素质量分数、溶质质量分数、化学方程式计算的「单位要统一、纯量才可以代入」。

`confusions` / `compares` / `examAngles` / `materials` / `questions` 与物理共用同一套形状。

## 四、图解 DSL

图**不用图片文件**：用数据描述图元，由 `src/components/PhysicsFigure.tsx`（理科共用渲染器）
画成内联 SVG。物理与化学**共用同一套 DSL**，化学另外多了装置与粒子图元。

### 4.1 坐标与通用图元

坐标是 **0—100 画布单位**，左上角为原点、y 向下；角度是度，0 = 正右、逆时针为正。
`view` 取 `wide`（100×62.5，装置图常用）/ `square`（100×100，溶解度曲线）/ `tall`（100×140，长导管装置）。

通用图元：`line` / `arrow`（可 `both`）/ `rect` / `circle` / `poly` / `arc` / `text` /
`angle`（`right: true` 画直角标记）/ `axis` + `curve`（坐标图像）/ `hatch`（斜线阴影）/
`dot`（标点：垂足、交点、光心；`hollow` 空心）。物理那批也都能用：
`beaker`（烧杯，`fill` 水位）、`thermometer`、`stopwatch`、`spring`、`lever`、`incline`。

### 4.2 化学图元

| 图元 | 参数 | 说明 |
| --- | --- | --- |
| `testTube` | `x y h? w? tilt? liquid? color? label?` | 试管；`liquid` 液面 0—1。**`tilt` 是顺时针旋转角（度）**：`0` 竖直（管口朝上）、**`100`—`110` 表示管口略向下倾斜**（如 `102`，加热固体的规范画法）、`80` 会让管口朝上——那是加热固体时最忌讳的画法，别用 |
| `flask` | `x y kind? h? w? liquid? color? label?` | `kind: 'conical'`（锥形瓶）或 `'round'`（圆底烧瓶） |
| `alcoholLamp` | `x y lit? label?` | 酒精灯；`lit: true` 画火焰 |
| `gasJar` | `x y w? h? liquid? color? cover? label?` | 集气瓶；`cover: true` 画玻璃片 |
| `funnel` | `x y kind? h? label?` | `'funnel'` 普通漏斗 / `'long'` 长颈漏斗 / `'sep'` 分液漏斗 |
| `stand` | `x y h? w? clamps? label?` | 铁架台；`clamps` 是铁夹高度比例数组，如 `[0.55]` |
| `atom` | `x y r? symbol charge? color? label?` | 原子/离子模型；`charge` 写在右上角（如 `'2-'`） |
| `molecule` | `x y atoms bonds? label?` | 分子模型：`atoms` 是相对分子中心的偏移（`dx dy r? symbol? color?`），`bonds` 是下标连线 |

**颜色是内容不是样式**：溶液的蓝色、沉淀的白色、固体的黑色都属于物质属性，
写在 `color` 里（可选值 `colorless` / `blue` / `yellow` / `green` / `brown` / `red` /
`purple` / `black` / `white`）。**无色透明写 `colorless`**：渲染器会给它画一条**液面线**，
所以「液面在哪、是否浸没、凹液面最低处」这些考点照样能从图上读出来；省略 `color` 则什么都不画。

## 五、练习：每个知识点不少于 8 道，且**全部过关才算掌握**

化学与物理用同一套掌握判定（`ChemTopic.questions` 就是这个知识点的**验收清单**）：

- `questions` **≥ 8 道**；题型混搭：`choice` ≥4、`fill` ≥1、`short` ≥2；
- `short` 里必须**至少 1 道化学计算题**（相对分子质量、质量分数、方程式计算，
  给 `answerSteps` 分步解题 + `rubric`）与 **至少 1 道实验探究/说理题**（给 `rubric`）；
- 整个知识点至少 **1 道配图题**（`choice` + `figure`，如给装置图判断操作正误、
  给溶解度曲线读数据）与 **至少 1 道作图/书写型题**（`short` + `answerFigure`，
  如画出粒子模型、画出装置连接、标出曲线上的点）；
- 每题都要有 `explanation`：**讲清为什么**，并逐一点出干扰项错在哪里
  （化学的错误选项常常是「现象描述错」「条件写错」「配平没配」三类，要点名）；
- 选择题答案字母分布均匀（校验器会告警单字母 >45% 或某字母缺失）；
- **判分是数值模式**：填空题的数值答案会按数值比较（`2.5` 与 `25` 不会互判为对），
  多种可接受写法用 `|` 分隔（如 `'5|5 g|5g'`）；化学式、离子符号这类答案要写成规范符号；
- 数据与现象必须**真实**：颜色、状态、溶解性、现象描述要与实验事实一致；
  计算题数据自洽（相对原子质量用整数：H 1、C 12、N 14、O 16、Na 23、Mg 24、Al 27、
  S 32、Cl 35.5、K 39、Ca 40、Fe 56、Cu 64、Zn 65、Ag 108、Ba 137）。

## 六、命名与结构约定

- 知识点 id：`chem-<模块短名>-<序号>`，如 `chem-matter-1`；题目 `chem-matter-1-q1`；
  材料题 `chem-matter-1-m1`，设问 `chem-matter-1-m1-q1`；图 id：`fig-chem-<主题>-<序号>`。
- `unit` 写教材归属：`'人教版九年级 · 第三单元 物质构成的奥秘'`（同一单元的多条内容共用同一个 `unit`，
  它同时是模块页的筛选标签）。册次：九上 = 第一至第七单元，九下 = 第八至第十二单元。
- `grade`：九上内容用 `'9a'`，九下用 `'9b'`，跨册综合用 `'all'`。
- 化学式下标用 Unicode 下标字符（H₂O、CO₂、Fe₂O₃、Ca(OH)₂），方便检索与朗读；
  化学方程式写成 `'2H₂ + O₂ —点燃→ 2H₂O'` 这种可读形式（条件写在箭头上方位置）。
- 中文引号统一「」；正文不使用 Markdown 加粗；行内公式用 `$...$`（可选）。

## 七、质量红线

1. **化学式、离子符号、化合价不能错**：写错一个下标就是教错（Fe₂O₃ 与 FeO、Na₂CO₃ 与 NaHCO₃）。
2. **方程式必须配平、条件必须写对**：不写条件、条件写错的方程式在中考直接不给分。
3. **现象描述要准确**：如「硫在氧气中燃烧发出明亮的蓝紫色火焰」而不是「黄色火焰」；
   「铁丝在氧气中燃烧火星四射，生成黑色固体」而不是「生成黑色气体」。
4. **实验安全与操作顺序不能反**：加热高锰酸钾要先撤导管后熄灯（防倒吸）、
   稀释浓硫酸要把浓硫酸倒入水中（不能反过来）、不能用嘴吹灭酒精灯。
5. **不做偏题怪题**，不超纲（初中化学课程标准和教材之外的内容不写）。
6. **不编造数据与年份真题**：`examAngles` 不填 `years`，材料题标「原创仿真」。
