# 高中目录索引（广东 2027 高考）——编写规范

本目录要回答一个问题：**广东 2027 年高考要考的东西，在教材的哪一册、哪一单元、哪一课时里。**
所以每科一份文件，每份都要有两种索引：

1. **按教材索引**：册次 → 单元（章）→ 课时（课文／节）→ 该处要掌握的核心点；
2. **按高考主题索引**：考点／题型 → 它会落在哪一册哪一单元哪一课时。

两种索引必须能互相查回去：同一件事在两个索引里出现的名称要一致。

## 一、先说清口径（每份文件开头都要写）

- **考试口径**：广东 2027 年高考（3+1+2）。语文、数学、外语用全国卷；物理、历史为首选科目，
  化学、生物、思想政治、地理为再选科目（等级赋分）。各科分值、时长、命题单位见 `README.md`。
- **教材口径**：写明本科在广东使用的教材**版本、出版年、册次清单**，并说明这一版是否就是
  2027 届（2024 年秋季入学）学生实际使用的版本；若近年有修订版，必须写清「修订版从哪一届开始用、
  2027 届用的是哪一版」，**不确定就写「未能核实」，不要猜**。
- **依据**：高考考什么以《普通高中课程标准（2017 年版 2020 年修订）》与广东省的考试安排为准；
  教材目录以出版社／教育行政部门的官方目录为准。**不使用「高考大纲」这个词**——高中课标之后
  没有考试大纲，正式说法是课程标准 + 考试要求。

## 二、核实等级（每个册次、每个单元都要标）

| 标记 | 含义 |
| --- | --- |
| ✅ | 已核对：至少两个独立来源一致（优先出版社官网／省级教育部门文件） |
| ⚠️ | 单一来源：只找到一处页面，未交叉核对 |
| ❓ | 未能核实：没找到可靠来源，**只写能确认的部分，其余留空并说明** |

**严禁编造**：单元名、课时名、课文标题、学分、页码一律来自资料。凭印象写出来的内容比留空更糟——
学生会照着它去复习。找不到就写「❓ 未能核实：XX 册第 X 单元名称未在公开资料中找到」。

## 三、每份文件的结构

```
# <科目>（广东 2027 高考）

## 一、教材版本与册次        ← 版本、出版年、册次、每册学分、2027 届是否适用（✅/⚠️/❓）
## 二、按教材索引            ← 逐册：单元 → 课时/课文 → 核心点
## 三、按高考主题索引        ← 考点簇 → 考查形式 → 对应册/单元/课时
## 四、来源清单              ← 每条一个 URL，标明它证明了什么
## 五、未核实清单            ← 明确写出哪些册/单元/课时没查到，缺什么
```

### 2.1 「按教材索引」的表格写法

每册一张表，表前一行写册名与版本（如「必修第一册（人教 A 版 2019）✅」）：

| 单元／章 | 课时／课文／节 | 核心点（考什么） |
| --- | --- | --- |
| 第一章 集合与常用逻辑用语 | 1.1 集合的概念；1.2 集合间的基本关系；… | 元素与集合的关系、集合运算… |

- **课时名要照抄教材**（如「1.3 集合的基本运算」），不要自己概括成「集合的运算」。
- 「核心点」是给学生看的：这一课时在中考／高考里怎么被考，控制在 15—40 字。
- 语文按「单元 → 课文（篇名 + 作者）」列，篇名要准（《沁园春·长沙》不要写成《沁园春长沙》）；
  单元后注明所属**学习任务群**（课标里的名称，如「文学阅读与写作」）。
- 课时／课文数量要与教材一致：**少一条就是漏了考点，多一条就是编造**。

### 2.2 「按高考主题索引」的表格写法

| 高考主题（考点簇） | 常见考查形式 | 对应册／单元／课时 | 备注 |
| --- | --- | --- | --- |
| 函数的单调性与最值 | 选择题、解答题第一问 | 必修第一册 第三章 3.2 | 常与导数联考 |

- 主题按**广东卷的题型结构**组织，不要照搬大学学科体系。
- 「备注」写命题习惯、易混点或与其它主题的联考关系，不写「必考」这类无法证实的断言。

## 四、来源与版权

- 每条事实后面能追到来源：在「来源清单」里给 URL + 一句话说明，正文用 [S1] [S2] 这样的编号引用。
- **只列目录（单元名、课时名、篇名）**，不抄教材正文、例题、插图；目录是事实性信息，正文有版权。
- 不写「某年真题」「某年考了 X」这类没有来源的断言；确需说明命题形态，写「近年广东卷常见形态」。

## 五、交付要求

- 只写自己那一份文件，不改 App 源码、不碰其它学科的文件。
- 不运行 `pnpm gen / check / validate / build`（协调方统一跑）。
- 不写临时脚本进仓库；需要统计或核对时用一次性命令。
- 完成后回报：每个册次的核实等级统计（✅/⚠️/❓ 各几个）、课时总数、未核实清单、你判断
  「2027 届用哪一版教材」的依据（贴来源）。
