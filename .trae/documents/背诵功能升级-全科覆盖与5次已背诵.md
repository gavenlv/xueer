# 背诵功能升级：全科覆盖 · 5 次「已背诵」 · 背诵明细

## 一、背景（为什么改）

用户需求：「所有文科要背诵的、记的，如古诗、文言文和其他科目的资料，都要加入背诵功能：遮住、背诵、按遗忘曲线，标注第一次、第二次……背诵时间，如果 5 次了就标注已背诵。」

**现状盘点**（重要：本功能大部分已存在，本次是**升级而非新建**）：

| 维度 | 现状 | 差距 |
| --- | --- | --- |
| 卡片覆盖 | `reciteCardsOf` 已覆盖语文（古诗/字词/文言文/现代文/作文/文学常识）、英语、历史、道法、数学 | 数据无缺口，**缺口在入口**：学科页只有语文放出「背诵」按钮 |
| 遗忘曲线 | 已实现 1→2→4→7→15→30 天 | 无缺口 |
| 达标口径 | 连续背对 **3** 次（跨三天）→「已标熟」 | 需改为累计 **5** 次（跨天）→「已背诵」 |
| 次数展示 | 只显示「已背 N 次」，**不显示时间是哪次** | 需保存并展示每次明细 |
| 遮住 | 知识点卡片是「看答案」翻面；逐句/逐段遮罩训练只有古诗词有 | 整篇遮罩需推广到文言文 |

**已与用户确认的口径**：
1. **5 次且必须跨天**——同一天重复点只算 1 次有效（最快 5 天完成），替换现有「标熟」终态。
2. **保存每次明细**——每张卡记录「第几次 / 时间 / 背了还是没记住」，可展开回看。
3. **已有卡片的科目全放开**（语文/英语/历史/道法/数学）；物理/化学维持「按逐题过关统计掌握」。
4. **卡片翻面不变 + 整篇遮罩推广到文言文**。

**必须继续遵守的既有硬约束**：卡片不写 `progress`；背诵队列在筛选确定时定好、作答中不重排；卡片从正文自动派生不另存数据；`useMemo` 依赖必须含数据就绪状态 `ready`；学科页是 `@data-summary-only`，不得加载正文。

## 二、改动方案

### 1. 类型与访问器 — `src/types.ts`、`src/lib/recite.ts`

`src/types.ts`（`CardRecord` 现约 L657）：

```ts
/** 单次背诵明细 */
export interface CardAttempt {
  at: number;       // 时间戳
  ok: boolean;      // 背了 / 没记住
  counted: boolean; // 本次是否计入跨天有效次数
}

export interface CardRecord {
  times: number;            // 累计打卡次数（每次点击都加，保留旧义）
  streak: number;           // 连续背对（同日不叠加、背错清零，保留旧义）
  lastAt: number;
  dueAt: number;
  masteredAt?: number;      // 旧「标熟」时间，仅作兼容兜底
  // —— 新增 ——
  effDays?: number;         // 跨天有效次数（新的达标依据）
  lastCountedAt?: number;   // 最近一次计入有效的时刻（同日判定用）
  attempts?: CardAttempt[]; // 每次明细，仅保留最近 20 条
  recitedAt?: number;       // 首次「已背诵」的时间戳
}
```

`src/lib/recite.ts` 新增访问器（**所有读取一律走访问器**，旧记录自动兼容）：

```ts
export const RECITE_TARGET_TIMES = 5;            // 原 RECITE_MASTER_STREAK 语义被替换
export const effectiveCount = (r?: CardRecord) => r?.effDays ?? r?.streak ?? 0;
export const isRecited = (r?: CardRecord) =>
  r?.recitedAt != null || effectiveCount(r) >= RECITE_TARGET_TIMES ||
  (r?.effDays == null && r.masteredAt != null);  // 旧「已标熟」卡不回退
export const toTarget = (r?: CardRecord) => Math.max(0, RECITE_TARGET_TIMES - effectiveCount(r));
```

- `isMastered` 重命名为 `isRecited`，调用点全量替换（`RecitePage`、`ReciteCards`、`StatsPage`、`UserMenu`、`DetailShell`）。
- `cardLevelLabel` 改读 `effectiveCount`，「已标熟」→「已背诵」。

### 2. 状态机 — `src/lib/recite.ts` 的 `applyCardRecite`

```
ok 且 !sameDay(lastCountedAt, now)：effDays+1、lastCountedAt=now、counted=true
ok 且  sameDay(lastCountedAt, now)：effDays 不变、dueAt 不变、counted=false（只算打卡）
!ok：effDays 不变（累计不清零）、dueAt=now+INTERVALS[0]*DAY、counted=false
每次 attempts.push({at, ok, counted})，截断保留最近 20 条
level = min(INTERVALS.length-1, max(0, effDays-1))；dueAt = 有效次那次按 level 推，其余不变
times += 1
recitedAt = prev.recitedAt ?? (effDays >= 5 ? now : undefined)   // 达成后粘住不清空
```

要点：**排期档位改由 `effDays` 推导**（累计口径，背错不清零、只把复习推到明天）；`streak` 保留仅作展示。间隔序列维持 `[1,2,4,7,15,30]`。

### 3. 同步合并 — `src/lib/sync.ts`

`cards` 合并由「整条 `lastAt` 新者胜」改为**字段级合并**（否则会丢明细、复活低计数）：

- `times` / `effDays` / `streak` / `lastCountedAt` 取 **max**（单调，不复活）。
- `attempts` 按 `at` 去重后**并集**，排序后截断最近 20 条。
- `recitedAt` 取两者中**已定义的较小值**（最早达成时间）。
- `lastAt` / `dueAt` 取 `lastAt` 较新者的值。
- `normalizeStudyState`（约 L18-33）内为每张卡补 `effDays/attempts` 默认值，保证旧数据可读、不写盘也能工作。

### 4. UI 展示 — `src/components/ReciteCards.tsx`

- `MasteryDots`：3 个点 → **5 个点**，读 `effectiveCount`。
- 顶部标签：`✅ 已标熟` → `✅ 已背诵`。
- 状态行：`已背 N 次 · 有效 M / 5 · X 天后复习`。
- **新增「背诵明细」折叠区**：`useState` 控制展开，逐条渲染 `第 i 次 · MM-DD HH:mm · ✅背了 / ❌没记住`（`counted=false` 的标注「今日重复打卡」）。默认折叠，避免长列表压页。
- 空态文案：`背满 5 次（跨天）即已背诵`。

### 5. 文案统一（「标熟」→「已背诵」）

`RecitePage.tsx`（页头说明、`STATUSES` 的「还没标熟/已标熟」、顶部 Stat、模块分组小字、底部说明）、`StatsPage.tsx`（`cardTotals` 相关 5 处）、`UserMenu.tsx`（右上角账户区的已背诵数）、`DetailShell.tsx`（详情页卡片区文案）、`index.css` 相关注释。口径说明统一为「每天最多算 1 次，累计 5 次即已背诵」。

### 6. 入口放开 — `src/pages/SubjectPage.tsx`

`toolsOf(subject)` 里把 `subject.id === 'chinese'` 换成**「本科有卡片」**判断，且**不加载正文**（本页是 `@data-summary-only`）：

```ts
// 与 ENTRY_META 同源的轻量清单，已在同一文件 import 自 ../data/summary
const CARD_MODULES = new Set(MODULE_TOTALS.filter((m) => m.cards > 0).map((m) => m.id));
const hasCards = subject.modules.some((m) => m.available && CARD_MODULES.has(m.id));
```

该名单与 `reciteCardsOf` 的分发 switch 自然对齐：物理/化学 `cards: 0` 自动无入口，语文/英语/历史/道法/数学自动获得。**不需要**给 `totals.ts` 的 `Totals` 加字段。

### 7. 整篇遮罩推广到文言文

- `src/components/ReciteTrainer.tsx`：props 由 `{ poem: Poem; entryId }` 泛化为 `{ lines: string[]; entryId: string; links?: boolean }`（内部继续用 `splitSegments` 切小段）；「返回篇目」类链接用 `links` 开关包住。
- `src/pages/detail/PoemDetail.tsx`：改为传 `lines={poem.lines}`（行为不变）。
- `src/pages/detail/ClassicalDetail.tsx`：新增 `<ReciteTrainer lines={按句切分(paragraphs)} entryId={entry.id} />`。`ClassicalText` 只有 `paragraphs: string[]`（无 `lines`），按 `。？！；` 切句后传入；`PoemText` 无需泛化（文言文用自有正文渲染）。
- 整篇记录同样纳入新口径：`ReciteRecord` 增加 `effDays/lastCountedAt/attempts/recitedAt`，`applyRecite` 追加明细，与卡片口径一致。
- `RecitePage` 底部「古诗词专门的遮罩训练」链接改为按当前科目指向对应篇目列表。

## 三、实施顺序

1. 类型 + 访问器（`types.ts`/`recite.ts`）——`pnpm validate` 旧用例应转红，作为改动生效的信号。
2. 状态机与常量（`recite.ts`）→ 同步更新 `validate-entry.ts` 的卡片用例，转绿。
3. 同步合并（`sync.ts`）+ 新增合并用例。
4. UI 与文案（`ReciteCards` / `RecitePage` / `StatsPage` / `UserMenu` / `DetailShell`）→ `pnpm smoke`。
5. 入口放开（`SubjectPage`）→ 补历史/数学背诵入口断言。
6. 整篇遮罩（`ReciteTrainer` / `PoemDetail` / `ClassicalDetail`）→ 补文言文遮罩断言。
7. 全量 `pnpm typecheck && pnpm validate && pnpm smoke`。

## 四、验证方式

- **自动化**：`pnpm typecheck`、`pnpm validate`、`pnpm smoke` 全绿。
  - `scripts/validate-entry.ts` 卡片用例重写：首次背对 `effDays=1`；同日重复不加 `effDays`；**跨 5 天 → 已背诵且 `recitedAt` 正确**；背错不清零但明细记 ❌；明细追加与截断 20 条；旧记录（无 `effDays`）按 `streak` 兼容读取。新增 `sync` 合并用例：明细并集不丢、`effDays` 取 max、`recitedAt` 取最早。
  - `scripts/smoke-entry.tsx`：断言历史/数学学科页出现「背诵」入口、物理/化学**不出现**；背诵页出现「已背诵」字样与「第 1 次」明细。
- **浏览器手测**：`/s/history/recite`、`/s/english/recite`、`/s/math/recite` 各点几张卡，确认次数、明细时间、达标文案；文言文详情页确认遮罩训练可逐段遮、可记录；学习报告与右上角数字口径同步为「已背诵」。

## 五、风险与取舍

- **已背诵数字回退**：门槛 3 → 5，旧卡即使兼容读也可能只有 3 次。方案用「旧 `masteredAt` 且无 `effDays` 视为已背诵」兜住存量。
- **口径放宽**：累计不清零 + 背错不降档，比原来更容易达成（原为连续背对跨三天）。
- **存储与同步体积**：约 1.5 万张卡，明细截断 20 条且只存 3 个短字段。
- **时区边界**：跨天判定用本地时区，跨时区设备可能多算一天（可接受）。
- **既有约束变更**：项目记忆里「连续背对 3 次（跨三天）标熟」的硬约束将被本次口径替换，实施后需同步更新 `project_memory`。
