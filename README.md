### 学习机制

- **练习引擎**：选择题、填空题与简答题统一判分，选择题选项每次练习都会重新打乱，避免靠位置记忆。
- **三种题型**：`choice` 四选一即时判分；`fill` 填空（忽略标点与空白，支持 `|` 备选写法）；`short` 简答题（揭示参考答案与踩分点后自评），对应广州中考名著附加题的真实考法。
- **默写题粒度自适应**：各篇 `lines` 的拆分粒度并不统一（近体诗按「联」、文言文常按长句或段落），若整行挖空会出现「一次默写 99 个字」的荒唐题目。因此默写题一律由 `makeReciteQuestions()` 下沉到「句」一级生成，用相邻句作上下句提示，并按字数给出难度。
- **即时解析**：每题作答后立刻给出对错、正确答案与解析，并标注知识点标签。
- **填空容错**：默写判定忽略标点与空白，只比对汉字，答案支持多种可接受写法（`|` 分隔）。
- **错题本**：自动收集错题，按模块归类；答对一次即减少计数、答对后自动移出；支持「只练错题」与整组重做。
- **学习进度**：每条内容的打开次数、答题正确率、最近学习时间、收藏、背诵打卡次数。
- **每日打卡与连续天数**：打开应用即完成当日打卡，顶栏显示连续天数。
- **学习报告**：总览数据、近 14 天答题趋势图、各模块完成度、由错题标签自动聚合的薄弱知识点、收藏列表。
- **学段切换**：七上 / 七下 / 八上 / 八下 / 九上 / 九下 / 全部，模块内容与练习范围同步切换。
- **全局检索**：模块内可按关键词与标签筛选。
- **响应式**：桌面为顶栏导航，手机为底部标签栏，竖排古诗文在窄屏自动调整间距。

数据全部保存在 `localStorage`（键名 `xueer.study.state.v1`），不上传任何服务器，可在「学习报告」页一键清空。

### 按中考要求组织的五个入口

「不只是跟着课文走，而是对着中考学」——这几块就是为此而建：

#### 🔗 知识联动（内容详情页自动生成）

每个内容页底部都有「关联学习」，**说明为什么相关**，而不是随机推荐：

| 关联类型 | 例子 |
| --- | --- |
| **同作者**（最强信号） | 《观沧海》→《龟虽寿》（同为曹操）；《夜雨寄北》→《无题》《贾生》（同为李商隐） |
| **同主题** | 《次北固山下》→《渡荆门送别》《商山早行》（同为思乡） |
| **同意象** | 《天净沙·秋思》→《使至塞上》（同用「夕阳」） |

关联由既有数据推导（作者、主题标签、从诗句中识别出的意象），并做了两层降噪：**出现比例过高的标签**（如「写景」）不予采用；**宽泛标签**（如「抒情」）必须另有强信号支撑——否则会出现「唐诗因为都『抒情』而关联到现代诗」这种没有教学价值的推荐。

#### 🧩 学一补多（跨模块串知识点）

「关联学习」解决的是**同类作品之间的横向比较**；「学一补多」解决的是另一件事：**学一篇时，顺带把其它模块的同源知识点一起补上**。它出现在每个内容页「关联学习」的正下方，按分组列出，每组都写明「补什么」：

| 分组 | 从哪里来 | 例子（《陋室铭》文言文版） |
| --- | --- | --- |
| **同一作品·其他模块** | 同一篇在别的模块还有一份，学法不同 | → 古诗词模块的《陋室铭》（逐句默写用） |
| **同作者·某某** | 同一作者的其它作品，跨模块（诗文一起看） | → 刘禹锡《秋词（其一）》《酬乐天扬州初逢席上见赠》 |
| **同一考点** | 考同一批知识点，可连起来做专项 | → 《爱莲说》《岳阳楼记》；并给出「🎯 就『宾语前置』做考点专项」直达链接 |
| **本篇涉及的字词** | 本篇正文里真的出现了该字词/成语条目 | → 顺手把释义补上 |
| **相关文学常识** | 标题与必记要点里提到该作家/作品 | → 作家作品、文学体裁、文化常识 |
| **同类作品·横向比较** | 同主题 / 同意象 | → 交给「关联学习」的规则，不重复推荐 |

三条降噪规则同样是回归测试的对象：

1. **考点必须「有区分度」**：每个知识点的权重按 `1/出现条目数` 计算（越稀有越有价值），并要求至少命中 1 个稀有标签才成组——否则任何两篇文言文都会因为「实词、注释」而互相关联。题库共 839 个知识点标签，正是这条规则把「同一考点」从 944 条压到 547 条有意义的关联。
2. **文学常识只在「标题 + 必记要点」里匹配**，不拿整篇 `content` 去匹配作者名——否则一处顺带提及就会造成假关联。
3. **「作者」为占位值时不成组**（佚名、无名氏，或直接以《书名》作作者的篇目），避免出现「同作者·佚名」这种空标题。

`pnpm validate` 对这两套联动规则做结构回归：分组完整（`kind`/`hint`/非空 `items`）、不自我指涉、不重复推荐、指向真实存在的条目、**「同一作品」关系必须对称**（A 指向 B，B 必须回指 A），并打印 2090 条学一补多关联与 1907 条关联学习的分布。`pnpm smoke` 则断言《陋室铭》详情页真的渲染出跨模块分组与考点专项入口——光跑路由渲染发现不了「组件没接进 `DetailShell`」这类漏接。

当前每个条目平均补出 4–7 个知识点，436 个条目中只有 2 首（《己亥杂诗（其五）》《庭中有奇树》）在题库里确实找不到同源内容。

#### 📅 今日背诵（间隔重复）

`/recite` 按遗忘规律安排复习：背对一次升一档，间隔 1 → 2 → 4 → 7 → 15 → 30 天；背错降档、次日重来。

背诵训练器提供**三级递进提示**：① 通读全文 → ② 首字提示（每句只留第一个字）→ ③ 完全遮住（只见句长）。学生自评后据此刻度下次复习时间。页面分「今天该复习 / 还没背过 / 已排期」三栏，可就地训练。

#### 🎯 中考考点（按考点刷题）

`/exam` 从题库的知识点标签**自动聚合出考点索引**——因此考点与题目天然对应，不会出现「考点没有题」。每个考点显示题量与题型分布、涉及的内容条目、**我在这个考点的错题数**。点「专项训练」就只刷该考点（`/practice/<模块>?tag=<考点>`）。

#### ✍️ 作文板块（从「只讲方法」扩到「能练」）

原作文模块只有方法讲解，学生**没有题可写**。现扩至 82 条，新增三个类别：

| 类别 | 条数 | 作用 |
| --- | ---: | --- |
| **作文题库** | 26 | 命题 8 · 半命题 7 · 材料 6 · 话题 5。每题含审题（**含两种跑偏理解及为何不对**）、三个层次的立意、具体选材方向、可套用提纲与字数配比、写作任务提示、原创开头示例 |

### 广州中考分值结构（穗教发〔2025〕32号，适用 2027–2029）

**语文**

| 项目 | 现行（2024–2026） | **2027 年起** |
| --- | --- | --- |
| 全卷总分 | 120 分 | **140 分** |
| 积累与运用 | 约 6 小题 24 分 | 约 6 小题 **28 分** |
| 阅读与鉴赏 | 约 14 小题 46 分 | 约 13 小题 **52 分** |
| 写作与表达 | 1 小题 50 分 | 1 小题 **60 分** |
| 附加题 | 名著阅读 8 分 | **整本书阅读 8 分** |
| 考试时长 | 120 分钟 | 120 分钟（不变） |

**数学**

| 项目 | 现行（2024–2026） | **2027 年起** |
| --- | --- | --- |
| 全卷总分 | 120 分 | **150 分** |
| 题量 | 25 题 | **25 题（不变）** |
| 选择 | 10×3 = 30 分 | 10×4 = **40 分**（推算） |
| 填空 | 6×3 = 18 分 | 6×4 = **24 分**（推算） |
| 解答 | 9 题 = 72 分 | 9 题 = **86 分**（推算） |
| 客观题占比 | 40.0% | **42.7%** |
| 考试时长 | 120 分钟 | 120 分钟（不变） |

数学的调整原则是官方表述的「**题型题量不变、考试时长不变、优化分值结构**」，通过提高选填单题分值实现平稳过渡。官方只公布客观题合计 64 分、且题量不变，**未逐题公布分值**，故上表逐题分值是按 16 道客观题平均推算，以当年官方印发的试卷结构说明为准。

两科均为**广州自主命题**（不使用广东省统一卷），全卷得分与附加题计分均不超过满分。

**关键差异 —— 广州语文附加题六年来从不考选择题。** 2021–2026 真题全部是表格/读书笔记补全、人物辨识、写人物小传、**比较探究**（最鲜明的命题技术）、补写内心独白、书籍推荐语判断等**主观表达题**，且每年跨 2~6 部名著考查。为此本应用新增了 **`short` 简答题题型**：

- 作答区为文本域；提交后揭示**参考答案**与**踩分点（rubric）**；
- 因主观题无法自动判分，由学生**对照自评**（基本答到了 / 没答到），自评结果照常进入错题本与统计；
- 已为 12 部名著编写 **36 道广州风格简答题**（每部 3 题，其中 **12 道为跨书比较题**）。
- 入口：「文学常识与名著」模块页 → **🎯 广州附加题专项（简答）**，对应路由 `/practice/literature?type=short&grade=all`。

## 三、数据契约

所有内容最终都会装配成统一的 `Entry`（见 `src/types.ts`），因此**列表页、练习引擎、错题本、统计只需要一套实现**：

```ts
type Entry =
  | { moduleId: 'poems';      data: Poem }
  | { moduleId: 'vocab';      data: VocabItem }
  | { moduleId: 'classical';  data: ClassicalText }
  | { moduleId: 'reading';    data: ReadingPassage }
  | { moduleId: 'writing';    data: WritingLesson }
  | { moduleId: 'literature'; data: LiteratureItem };

// 公共字段：id / title / subtitle / grade / tags / searchText / questions
```

练习题统一为 `QuizQuestion`：

```ts
{
  id, type: 'choice' | 'fill' | 'short', stem, options?, answer,
  explanation, difficulty?, tags?, rubric?
}
```

- `choice`：**恰好 4 个选项**，`answer` 为 `'A' | 'B' | 'C' | 'D'`。
- `fill`：**不设 options**，`answer` 为精确文本；多种可接受写法用半角 `|` 分隔。
- `short`：**不设 options**，`answer` 为参考答案，`rubric` 为踩分点数组，供学生对照自评。

`pnpm validate` 会检查 id 全局唯一、字段完整性、选项数量、答案合法性、`lineNotes` 与 `lines` 数量一致、简答题必须有踩分点等规则，并输出各模块内容量与题目量统计。

## 四、如何扩展

### 增加语文内容

在 `src/data/chinese/` 下对应文件里按接口追加条目即可，无需改动任何 UI 代码 —— 列表、检索、组卷、错题、统计会自动包含新内容。追加后跑 `pnpm check`。

### 新增学科

架构已做成学科无关：页面只依赖 `src/data/index.ts` 提供的聚合 API，**新增学科时 UI 一行都不用改**。

1. 在 `src/types.ts` 的 `ModuleId` 联合类型中加入该学科的模块 id，并定义该学科的内容模型（如数学的 `MathTopic`）与 Entry 变体。
2. 新建 `src/data/<subject>/index.ts`，把数据装配成 `Entry[]`，导出 `allEntries` / `mindMaps` / `extensions`。
3. 在 `src/data/index.ts` 中 `import` 并展开到全局聚合里（三行）。
4. 在 `src/data/subjects.ts` 里把该学科的 `available` 置为 `true` 并填好 `modules` —— 首页、学科页、统计页会自动出现它。
5. 如有专有呈现方式，在 `src/pages/detail/` 增加渲染器并在 `DetailPage.tsx` 的 `switch` 中注册。

首页、学科页、模块列表页、练习页、错题本、统计页与知识拓展页都是数据驱动的；`scripts/validate-entry.ts` 与 `scripts/smoke-entry.tsx` 也已遍历全部学科，新学科的数据与页面会自动纳入校验。知识联动（`src/lib/relations.ts`）同样只依赖统一 `Entry`，新学科无需另写关联代码——但要注意它**只在同学科内建立关联**，数学与语文的知识点不会混在一起。

## 五、实现说明

- **技术栈**：Vite + React 18 + TypeScript。路由用 `HashRouter`，因此部署到任意静态托管（含子目录）都不需要服务端 rewrite 规则；`base: './'` 让资源路径为相对路径。
- **关于直接打开 `dist/index.html`**：不可以。浏览器为安全起见禁止通过 `file://` 加载 ES 模块（`type="module"`），请用 `pnpm dev` 或 `pnpm preview` 通过 http 访问。
- **样式**：手写 CSS 设计系统，CSS 变量统一管理配色与圆角阴影；配色取「宣纸 + 墨 + 朱砂 + 黛蓝」，古诗文用楷体/宋体呈现，正文用系统无衬线字体。
- **古籍排版**：古诗文支持 `writing-mode: vertical-rl` 竖排；点击诗句即可遮住该句用于自测。
- **无依赖后端**：全部离线，数据存 `localStorage`。
- **现代文阅读原文与范文均为本项目原创撰写**，未摘抄任何现当代作家作品。
